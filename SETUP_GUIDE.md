# 🚀 RAG Notes Assistant - Full Setup Guide

This document explains how to set up and run the entire RAG application (both backend and frontend).

## 📋 System Requirements

- Node.js v14+ installed
- npm or yarn
- A terminal/command prompt
- Your backend API running (Express server)

## 📁 Project Structure

```
notes-RAG app/
├── src/                 (Backend - Express)
│   ├── server.js
│   ├── config/

│   ├── src/

│   ├── vite.config.js
```

## 🔧 Setup Instructions

### Step 1: Backend Setup

Navigate to the backend root directory:

```bash
cd "notes-RAG app"
```

Install backend dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm run dev
```

You should see output like:
```
Server running on http://localhost:5000
Database connected
```

**Keep this terminal open!** The backend needs to stay running.

### Step 2: Frontend Setup

Open a **new terminal** and navigate to the frontend:

```bash
cd "notes-RAG app/frontend"
```

Install frontend dependencies:

```bash
npm install
```

Start the frontend development server:

```bash
npm run dev
```

You should see output like:
```
VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
```

A browser window should automatically open. If not, visit `http://localhost:5173` manually.

## ✅ Verify Everything is Working

### Backend Verification

Check backend is running:
- Terminal shows "Server running on http://localhost:5000"
- Make a test request: Open browser and visit `http://localhost:5000/api/health`

### Frontend Verification

Check frontend is running:
- Browser shows the RAG Notes Assistant UI
- The page has three main sections: Upload, Ask Question, Answer

### Connection Verification

Test the connection:
1. In frontend, try to upload a file
2. Look at browser Network tab (F12 → Network)
3. You should see POST request to `/api/notes/upload`
4. Response should show success message

If you see CORS errors:
- Ensure backend is running on port 5000
- Check vite.config.js proxy settings

## 🧪 Testing the Full Flow

### 1. Upload a Document

1. Click "Choose a PDF or TXT file" in the left panel
2. Select a PDF or TXT file from your computer
3. Click "Upload File"
4. Wait for success message

If upload fails:
- Check file size (should be reasonable)
- Check file format (PDF or TXT)
- Check console for error messages

### 2. Ask a Question

1. Type a question in the middle panel
   - Example: "What is deadlock?"
2. Click "Ask Question" or press Ctrl+Enter
3. Wait for answer (shows "Thinking..." spinner)

If question fails:
- Make sure you uploaded a file first
- Check the console for error messages
- Backend might still be processing

### 3. View the Answer

1. Answer appears in the right panel
2. Should be generated by the Gemini API based on your documents
3. Click next to answer to see formatting

## 📝 Common Issues & Solutions

### Port Already in Use

**Error**: `EADDRINUSE: address already in use :::5000`

**Solution**: 
- Another app is using port 5000
- Option 1: Close the other app
- Option 2: Change port in backend (config/db.js or server.js)
- Option 3: Kill the process:
  ```bash
  # Windows
  netstat -ano | findstr :5000
  taskkill /PID <PID> /F
  
  # Mac/Linux
  lsof -i :5000
  kill -9 <PID>
  ```

### CORS Errors

**Error**: `Access to XMLHttpRequest blocked by CORS policy`

**Solution**:
- Backend CORS might not be configured
- Add to backend server.js:
  ```javascript
  app.use(cors());  // Allow all origins
  ```

### Axios Not Finding Backend

**Error**: `Network Error` when uploading/asking

**Solution**:
- Verify backend is running: `http://localhost:5000`
- Check vite.config.js proxy settings
- Try direct URL: `http://localhost:5173/api/notes/upload`

### Hot Reload Not Working

**Issue**: Changes don't appear after saving

**Solution**:
- Frontend might not be running in dev mode
- Restart frontend: `npm run dev`
- Clear browser cache (Ctrl+Shift+Delete)

## 🎯 Architecture Overview

### Request Flow

```
User Action (Upload/Ask)
    ↓
React Component (FileUpload / QuestionForm)
    ↓
API Service Layer (api.js)
    ↓
Axios HTTP Request
    ↓
Vite Proxy (/api → localhost:5000)
    ↓
Express Backend
    ↓
Process Request (Upload → DB, Ask → RAG + Gemini)
    ↓
JSON Response
    ↓
API Service returns data
    ↓
Component updates state
    ↓
React re-renders UI
    ↓
User sees result (Success/Error/Answer)
```

### Component Communication

```
Home (State Management)
├── Props Down: uploadedFile, isLoading, error, answer
├── Callbacks Up:
│   ├── FileUpload → onUploadSuccess()
│   └── QuestionForm → onAsk(question)
└── Child Components
    ├── FileUpload (handles upload)
    ├── QuestionForm (captures question)
    └── AnswerBox (displays answer)
```

### Check Logs

**Backend Terminal**:
- Look for error messages
- Check database connection messages

**Frontend Console** (F12):
- Look for JavaScript errors
- Check Network tab for failed requests

### Common Error Messages

| Error | Cause | Fix |
|-------|-------|-----|
| Cannot POST /api/notes/upload | Backend not running | Start backend |
| CORS error | Backend doesn't allow frontend origin | Configure CORS in backend |
| Network Error | Connection issue | Check backend URL in vite.config.js |
| File too large | Upload limit exceeded | Check backend file size limit |

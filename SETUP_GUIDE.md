# 🚀 RAG Notes Assistant - Full Setup Guide

This document explains how to set up and run the entire RAG application (both backend and frontend).

## 📋 System Requirements

- Node.js v14+ installed
- npm or yarn
- A terminal/command prompt
- Your backend API running (Express server)

## 📁 Project Structure

```
notes-RAG app/
├── src/                 (Backend - Express)
│   ├── server.js
│   ├── config/
│   ├── controllers/
│   ├── middleware/
│   ├── models/
│   ├── routes/
│   └── services/
├── frontend/            (React - Vite)
│   ├── src/
│   ├── package.json
│   ├── vite.config.js
│   └── index.html
└── package.json         (Backend package.json)
```

## 🔧 Setup Instructions

### Step 1: Backend Setup

SET .env FILE:
  PORT=5000
  MONGO_URI=YOUR_MONGO_URL
  GROQ_API_KEY=UR_AI_API_KEY
  NODE_ENV=development


Navigate to the backend root directory:

```bash
cd "notes-RAG app"
```

Install backend dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

You should see output like:
```
Server running on http://localhost:5000
Database connected
```

**Keep this terminal open!** The backend needs to stay running.

### Step 2: Frontend Setup

Open a **new terminal** and navigate to the frontend:

```bash
cd "notes-RAG app/frontend"
```

Install frontend dependencies:

```bash
npm install
```

Start the frontend development server:

```bash
npm run dev
```

You should see output like:
```
VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
```

A browser window should automatically open. If not, visit `http://localhost:5173` manually.

## 🧪 Testing the Full Flow

### 1. Upload a Document

1. Click "Choose a PDF or TXT file" in the left panel
2. Select a PDF or TXT file from your computer
3. Click "Upload File"
4. Wait for success message

If upload fails:
- Check file size (should be reasonable)
- Check file format (PDF or TXT)
- Check console for error messages

### 2. Ask a Question

1. Type a question in the middle panel
   - Example: "What is deadlock?"
2. Click "Ask Question" or press Ctrl+Enter
3. Wait for answer (shows "Thinking..." spinner)

If question fails:
- Make sure you uploaded a file first
- Check the console for error messages
- Backend might still be processing

### 3. View the Answer

1. Answer appears in the right panel
2. Should be generated by the Gemini API based on your documents
3. Click next to answer to see formatting


## 🎯 Architecture Overview

### Request Flow

```
User Action (Upload/Ask)
    ↓
React Component (FileUpload / QuestionForm)
    ↓
API Service Layer (api.js)
    ↓
Axios HTTP Request
    ↓
Vite Proxy (/api → localhost:5000)
    ↓
Express Backend
    ↓
Process Request (Upload → DB, Ask → RAG + Gemini)
    ↓
JSON Response
    ↓
API Service returns data
    ↓
Component updates state
    ↓
React re-renders UI
    ↓
User sees result (Success/Error/Answer)
```

### Component Communication

```
Home (State Management)
├── Props Down: uploadedFile, isLoading, error, answer
├── Callbacks Up:
│   ├── FileUpload → onUploadSuccess()
│   └── QuestionForm → onAsk(question)
└── Child Components
    ├── FileUpload (handles upload)
    ├── QuestionForm (captures question)
    └── AnswerBox (displays answer)
```
